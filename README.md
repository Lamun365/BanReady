# BanReady

BanReady helps Worcester drivers check winter parking restrictions and find parking alternatives during active parking bans.

## Access BanReady

### 🌐 Web App (iPhone, iPad, Desktop)

[Open BanReady Web App](https://banready-web.onrender.com/)

### 📱 Android APK

[Download Android APK](https://github.com/Lamun365/BanReady/releases/download/v1.0.0/BanReady.apk)

## Features

- Winter parking ban compliance checking
- Nearby parking recommendations
- Street Chance analytics
- Parking Zone analytics
- Walking Zone analytics
